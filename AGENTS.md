# Antigravity Agent Configuration & Rules

## Automation & Autonomous Execution Policy
- **Auto Execution**: Automatically execute terminal commands, test suites, builds, and file edits without asking for step-by-step confirmation.
- **Git Operations**: Automatically stage, commit with clear descriptive messages, and push changes to GitHub when completing tasks.
- **Testing**: Always run unit tests automatically after modifications to ensure 100% pass rate.
- **Proactive Problem Solving**: When encountering issues, diagnose and fix them immediately without blocking or asking redundant questions.
- **Language**: Respond in Vietnamese when addressed in Vietnamese.
